\# 一箭又一箭（Arrow Escape）



\## 游戏简介



点击式箭头解谜小游戏。棋盘上分布若干带方向的箭头（上、下、左、右）。

点击箭头时：



\- 若其前进方向到棋盘边界之间没有其他箭头 → 箭头飞出并消除；

\- 若前方有箭头阻挡 → 不能消除，失误次数 +1；

\- 每关 3 次失误，用尽即失败；

\- 清空全部箭头即通关，进入下一关。



\## 开发环境



\- Python 3.10

\- pygame 2.5.0

\- pytest（仅测试用）



\## 安装与运行



```bash

pip install pygame

python main.py

```



\## 操作说明



| 操作 | 效果 |

|------|------|

| 鼠标左键点击箭头 | 无阻挡则飞出；有阻挡则失误 +1 |

| 点击左上角“重新开始” | 当前关卡恢复初始状态 |

| 开始界面点击“开始游戏” | 进入第 1 关 |

| 结果界面点击任意位置 | 返回开始界面 |



\## 关卡说明



共 3 个关卡，均已人工试玩验证可通关：



\- 关卡 1：4×4，4 个箭头，入门

\- 关卡 2：4×4，4 个箭头，简单

\- 关卡 3：5×5，9 个箭头，含“先清障”设计
